# 一箭又一箭

## 项目简介

“一箭又一箭”是一款使用 Python 和 Pygame 开发的点击式箭头解谜游戏。

游戏棋盘中包含上、下、左、右四种方向的箭头。玩家需要判断箭头前进方向上是否存在其他箭头，并按照正确的顺序点击箭头，使所有箭头飞出棋盘。

## 游戏规则

- 使用鼠标点击棋盘中的箭头。
- 如果箭头前方没有其他箭头阻挡，箭头会飞出棋盘并消失。
- 如果箭头前方存在其他箭头，箭头不会消失，并触发碰撞反馈。
- 点击被阻挡的箭头会消耗一次失误机会。
- 清除当前关卡中的全部箭头后进入下一关。
- 失误次数耗尽后挑战失败，可以重新开始当前关卡。

## 开发环境

- 操作系统：Windows
- 开发工具：Visual Studio 2022
- Python：3.9.13
- Pygame：2.6.1
- 版本管理：Git、GitHub

## 安装方法

确保电脑已经安装 Python，然后在项目目录中执行：

```bash
python -m pip install -r requirements.txt
```

也可以直接安装 Pygame：

```bash
python -m pip install pygame
```

## 运行方法

在 Visual Studio 中打开项目，将 `OneArrowAgain.py` 设置为启动文件，然后按：

```text
Ctrl + F5
```

也可以在项目目录中执行：

```bash
python OneArrowAgain.py
```

## 操作说明

1. 启动游戏。
2. 点击“开始游戏”按钮。
3. 使用鼠标左键点击棋盘中的箭头。
4. 根据箭头方向和阻挡关系选择正确的消除顺序。
5. 清除全部箭头即可完成当前关卡。
6. 可以点击“重新开始”按钮恢复当前关卡。
